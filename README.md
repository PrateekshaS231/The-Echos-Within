# The Echos Within

A Virtual Reality Escape Room Experience developed using Unity and the XR Interaction Toolkit.

## About the Project

**The Echos Within** is an immersive VR escape room game where players explore a series of puzzle-based rooms, interact with objects, solve challenges, and unlock doors to progress through the experience.

The project focuses on interactive puzzle design, VR object interactions, and creating an engaging environment for virtual reality gameplay.

## Features

- **Color Matching Puzzle:** Identify and match colors to solve the room's challenge.
- **Button Sequence Puzzle:** Memorize and reproduce the correct sequence of buttons.
- **Jigsaw Puzzle:** Assemble puzzle pieces to complete the challenge.
- **Keypad Puzzle:** Solve a numeric code to unlock a door.
- **Fruit Placement Puzzle:** Place fruits in the correct positions to complete a logic-based challenge.
- **Interactive VR Environment:** Interact with objects and puzzle elements in a virtual escape room.
- **Door Unlocking System:** Progress through the rooms by completing puzzles.

## Technologies Used

- **Game Engine:** Unity
- **Programming Language:** C#
- **VR Development:** XR Interaction Toolkit
- **Interaction System:** XR Interactables and VR interaction components

## Gameplay

Players explore the escape room and solve puzzles using virtual reality interactions. Each room presents a different challenge, encouraging observation, logical thinking, and problem-solving.

Complete the puzzles to unlock doors and continue progressing through the experience.

## Project Structure

The project follows the standard Unity project structure.

- `Assets/` — Game assets, scenes, scripts, and other project resources.
- `Packages/` — Unity package dependencies.
- `ProjectSettings/` — Project configuration and settings.

## Installation and Setup

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the downloaded project folder.
4. Open the project using a compatible Unity version.
5. Open the main game scene from the `Assets` folder.
6. Connect a compatible VR headset or configure the available XR simulator, depending on your setup.
7. Press **Play** to run the experience.

*Note: The exact Unity version, main scene, and headset compatibility should be confirmed before running the project.*
